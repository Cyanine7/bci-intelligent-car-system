# 速度环实验与电机模型设置

入口为主窗口顶部第二个页签“速度环实验”，打开后依次为“电机模型”“PI 参数”“阶跃执行”“曲线与指标”。未连接时可编辑模型、计算参数和预测响应；连接并完成能力查询后，按设备实际状态开放配置与执行。

主窗口按任务分为三个页签：“实时监测”显示遥测、曲线和通信日志；“速度环实验”用于模型、PI 设计和两段实验；“设备与调试”集中串口/蓝牙、协议、保存配置、旧版设备功能及手动发送。启动显示实时监测，连接详细信息默认隐藏。连接/断开、录制和 STOP 位于顶部，切换页面后仍可操作。

当前生产源码使用“增量PI＋目标前置滤波”；新BIN已构建，尚未在本轮烧录。执行前必须由真实CAPS同时确认算法就绪和目标滤波能力。旧未滤波固件不能执行本版闭环实验，面板显示升级原因；开环能力保留。

## 电机模型

启动默认选择负载，使用用户于2026-10-22指定的参数：左K=7.20687e-5、τ=0.102s，右K=7.21277e-5、τ=0.098s，来源为2026-10-15负载正向2秒+2秒测量。切换到空载仍使用满电12.6V模型：左K=7.646220324939004e-5、右K=7.598223770509158e-5，左右τ均0.059s；历史非满电空载可在模型下拉框选择。可独立修改左K、左τ、右K、右τ，空载/负载分别保留本次会话草稿。K单位为(m/s)/PWM整数单位，τ单位秒，支持科学计数法与17位有效数字。模型表示4000附近局部增量关系。

每个工况保留会话草稿；“恢复当前工况默认模型”恢复四个默认值。“保存为自定义模型”需要新名称，可填写参考电压和备注；模型保存在config/motor_models.json，不覆盖原始数据。下次启动仍采用默认模型，自定义模型通过下拉框选择。文件损坏时提示并回退默认。当前电压显示来自遥测，并标明是否过期。

修改模型不会发送命令或改写设备参数。开环辨识完成后，可“辨识结果复制到模型草稿”，再保存。

## PI草稿

- 直接输入左右Kp、连续Ki。
- 按Mp/ts计算：Mp界面单位%，例如10代表函数的0.1。默认5%、ts=0.20s，均可自由修改。左右分别按当前K、τ直接计算：ζ=−ln(Mp)/sqrt(π²+ln²(Mp))、ωn=4/(ζts)、Kp=(2ζωnτ−1)/K、Ki=τωn²/K。Mp和ts是二阶理论设计值，不是上限。程序不优化、不自动替换参数；公式出现负Kp或超设备范围时明确说明原因。
- 计算只填入草稿。模型或设计指标变化后需重算，或切换为直接输入。
- 计算所得参数还可手动修改，记录来源会变为手动。
- “应用草稿并回读”需要新鲜STATE、失能、本地无其他控制权；以匹配ACK和binary64回读为生效依据。
- “实际复制到草稿”只复制设备参数，不发送。
- 执行前草稿必须与已确认RAM逐字节一致。修改模型后需重新计算，再应用并回读；执行按钮会显示具体未就绪原因，不能用新模型草稿悄悄执行旧PI。
- Ki是连续积分增益；每周期仅由MCU乘一次实际dt。新接口没有q100舍入。
- 界面与协议统一为“增量PI＋目标前置滤波”，不另设算法切换选项。

目标前置滤波固定启用：左右各自使用Tf=Kp/Ki，rf += dt/(Tf+dt)×(r−rf)，再以rf−v进入原增量PI。Kp=0时Tf=0、目标直接通过。非零目标切段保留滤波与PI状态，零目标/STOP/失能/故障立即归零。当前Mp/ts参数公式保持不变，其中ts=4/(ζωn)仍是2%调节时间近似式。

上下文分别冻结PI生成时模型、实验预测模型、实际PI参数和滤波能力；修改界面不覆盖已执行记录。图中分别显示原始目标、进入PI的滤波目标、五点平滑速度及原始反馈；Mp/ts从原始目标阶跃计时和归一化。历史记录未声明滤波能力时，导出按旧的未滤波模型重算。

## 两种阶跃模式

开环输入为两段左右PWM；闭环输入为两段左右目标速度mm/s。输入初值全零，默认每段1500ms，必须自行设置两段不同输入。总时长不超过3000ms，新实验PWM上限16500，闭环目标每轮不超过1180mm/s。同轮两段非零输入不得跨方向。

操作顺序：查询版本2实验能力 → 闭环时应用并回读PI → 显式使能对应模式并等STATE → 执行两段一次 → 等待到期失能及后200ms采样 → 刷新概要和阶段数据 → 读取完整100Hz记录。

STOP立即取消剩余段。一次命令原子提交两段，由MCU切换，运动中不续租、不重复提交。旧设备拒绝新查询时仍可用原有功能。切换界面模式会把执行输入清零，防止PWM与mm/s混用。

## 预测与结果

“刷新预测与阶跃范围”使用当前模型和草稿，不发送。未设置有效两段输入时，曲线明确采用计算示例，执行值仍为零。分别显示二阶理论设计值、完整PI连续模型预测、含周期平均反馈/整数PWM/限幅的离散预测；直接报告预测相对理论的ΔMp（百分点）与Δts（秒），不会根据预测调整公式所得PI。普通PI的闭环零点和离散实现可能使预测不同于二阶理论值，实际测量再独立比较。非零起点预览PWM0为线性模型估计；实验后按实际第一平台复核。另显示首周期范围、95%建议范围及整条PWM峰值。

完整记录包含100ms前窗、运动阶段和200ms后窗。两段平台用末300ms完整编码器增量统计并检查趋势。开环计算增量K、63.2%粗读数和计数窗拟合τ；闭环计算v0/v∞、静差、目标跟踪超调、平台超调、上升时间、调节时间、PWM峰值及限幅时长。目标超调和2%时间统一以目标与实测起点的差值归一化。模型设计结果和实测结果分别报告。

实测速度采用当前点及前四点的等权滑动平均：v平滑[n]=(v[n]+v[n−1]+v[n−2]+v[n−3]+v[n−4])/5。实时曲线、下载后的曲线、超调、上升时间及2%调节时间估计共用同一平滑速度；误差曲线使用进入PI的滤波目标减去平滑速度。平滑速度以粗线显示，原始速度以淡色细线保留；PWM及目标曲线按原值显示。

开始时积满五点才输出，不补零；切段保持窗口连续，丢样或非法周期后重新积满五点。保留当前点时间戳，10ms采样时窗口覆盖50ms、约滞后20ms，不前移时间来缩短ts。平滑会压低峰值，不能恢复被量化丢失的瞬时速度。ts估计取平滑曲线最后一次离开目标±2%阶跃幅值误差带后的首个样本，后续至少观察100ms并始终在带内；观察不足则不给估计。

原始10ms速度、指标、峰值编码器计数/周期和计数量化区间继续保留。超调和调节时间的量化区间也用相同五点窗，不再另加自适应长窗；计入起点平台量化及窗口支撑，不足时仍保留未确定上界。导出的samples.csv和sample_hex保持原始数据，summary.json的analysis.wheels各轮新增smoothed指标，原有字段保留原始口径。

每次执行冻结理论Mp/ts、模型、实际RAM参数和revision。读取后报告实测相对理论的有符号差值/区间，并说明“实测高于理论／实测低于理论／测量区间包含理论值／无法比较”。不再按最大值判达标。区间包含理论值不等于已经证明二者相同，计数窗会平滑瞬时峰值。平台不足、故障、缺口或尚未切段时保留数据并说明原因。未发生阶跃的轮不参与；目标降为零属于停止响应。

新实验被MCU接受后立即切换当前run，清除旧曲线和旧指标，等待本次记录；缓存包含连接、run、revision与记录代次，不会因样本数相同而沿用上次结果。完整记录的PI/revision还必须与执行时确认的RAM一致。

“曲线与指标”可开关平台、目标、切段、63.2%、2%带和峰值等辅助线。暂停显示不影响采样。完整读取后自动保存data/speed_时间_标识/samples.csv和summary.json，也可再次手动导出；每次导出新目录。导出保存配置、模型、设计依据、电压范围、阶段、原始样本十六进制及分析结论。
