## 尚未验证及实车联调顺序

本轮未修改或烧录 MCU；没有执行本程序的真实蓝牙扫描、配对、RFCOMM 连接、实车无线遥测、真实串口占用/拔线或真实发送失败验证。用户此前完成的无线烧录不等于这些测试已通过。

1. 核对电脑蓝牙适配器、模块实际型号和当前应用固件。首次配对在 Windows 设置中完成。
2. 核对实际名称、MAC 与 RFCOMM 通道。默认 1 只是初始配置；不能用历史烧录工具地址认定当前设备。
3. 核对模块与 MCU 的 UART 配置；当前主工程 USART2 为 230400、8N1。电脑 RFCOMM 没有这一波特率配置项。
4. 使用蓝牙 SPP 模式扫描或填入地址并连接，分别检查链路状态与有效遥测；核对原始 C 帧、轮速幅值单位、电量和约 20 Hz 接收频率。
5. 开始录制，暂停日志/曲线显示后继续采集，停止后核对 CSV 与日志中的来源、连接身份和设备配置。
6. 验证模块掉电、恢复供电与重复连接；应显示断线/数据过期，启动和恢复供电不自动重连，不重发旧请求。
7. 如需验证原始发送，先按固件源码确定可发送的测试字节；写出结果不能当作 MCU 接受。当前程序不自动发送复位、AT 配置或烧录指令。
