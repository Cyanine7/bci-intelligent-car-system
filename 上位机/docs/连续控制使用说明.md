# 连续驾驶与可切换操控

2026-11-04：默认使用**离散指令、连续驾驶**。原来的“按住方向键＋Z/X”保留在页面的“操控模式”下拉框中。切换模式会STOP、清空两轴和未处理输入，必须重新使能；重启或新连接回到默认模式。

## 准备

1. 重启上位机，设备更新为连续控制扩展v2固件。查询实际连续CAPS；v1显示“需更新连续驾驶固件”，两种操控均不启用。
2. 查询闭环能力，应用并回读角速度外环和左右轮PI参数。在连续页读取参数、静止采集零偏（2s），确认新鲜STATE、本地允许与IMU就绪。
3. 选择操控模式和速度幅值，点击“使能连续控制”。焦点进入操纵区，确认后输入方向。使能从两轴中立开始，不恢复旧方向。

控制参数仍只写RAM；使能冻结revision、内外环PI、PWM/差速上限与零偏，不自动改增益。首次使能STATE仍要求500ms以内。

## 默认：离散指令、连续驾驶

| 输入 | 作用 |
|---|---|
| ↑ / ↓ | 更新前后轴：同向保持、反向一次抵消为中立，再按才反向 |
| ← / → | 按相同规则更新转向轴，可与前后轴叠加 |
| 松键 / 没有新指令 | 保持方向与速度幅值 |
| W / S | 线速度幅值每次＋/－0.05m/s |
| A / D | 角速度幅值每次－/＋0.10rad/s |
| 空格 / STOP | 立即停车并失能，清空方向与待处理输入 |

初始幅值为0.10m/s、0.30rad/s；各自允许0～实际CAPS上限，独立限幅。达到上限不积累隐藏数值，减小一次立即生效。幅值减到0仍保留方向，增加后沿该方向运动。系统长按自动重复被忽略，同批同轴相反输入确定归零。

例如依次点按“↑、←、D、→、↓”：前进→前进左转→增强左转→回正继续前进→平滑减速至零。每次松键都保持当时状态；前进左转时再次↑不会回正。

倒车加左/右分别向左后/右后，MCU角速度符号随倒车反转；没有平移时左右为原地逆/顺时针旋转。高亮显示锁存方向，页面同时显示方向状态、幅值、请求目标、执行参考及实际反馈。

正常目标归零按0.5m/s²、2rad/s²过渡，执行参考都到零后清控制器；途中不因普通方向变化重建PI或前置滤波。STOP、故障与期限到期仍立即清状态和PWM。

## 可切换：原操控

选择“按住方向键 · Z/X调速（原操控）”。方向键按住运动、组合转弯，松开对应轴立即归零，全松清三环/PWM并保持使能。Z/X共同倍率×1.1/×0.9，长按每200ms调整，范围10%～1000%；相反方向同时按下抵消，Z/X同时按下不调速。倍率按当前方向实际CAPS约束，不隐藏累积。

原操控保持2Hz、200ms ACK、500ms基础STATE、200ms连续遥测及1000ms目标期限；松键归零绕过普通目标间隔与在途请求。新MCU的ARM空闲期统一为2000ms，Host仍按原200ms检查ARM确认。

## 通信容错与停止

默认模式每500ms发送一次最新目标（2Hz），方向或速度变化也等到下一次发送。上一条目标的ACK迟到或通信积压时，发送间隔会延长。每次发送当前的绝对v/omega。MCU闭环100Hz、独立反馈20Hz。

| 默认模式检查 | 行为 |
|---|---|
| ACK等待≥200ms | 显示延迟；≥600ms停止，不重发 |
| 连续遥测年龄≥300ms | 提示抖动；≥1000ms停止 |
| 运行中基础STATE年龄≥500ms | 提示延迟；≥1000ms停止 |
| 设备RX/TX丢弃计数增加 | 保留真实计数、告警；单独不停止 |
| 未溢出的主机积压 | 暂停普通目标、优先排空；持续500ms停止 |
| 真实缓存溢出 | 立即停止 |
| 目标/ARM设备期限 | 上限2000ms，按u32绝对时间检查 |

连续遥测按接收线程的原始收包时间计算年龄，重复或倒序tick/序号不刷新新鲜度。参数revision变化、设备失能或退出mode6、本地禁止、明确拒绝、真实断连和IMU无效直接结束驾驶；陀螺60ms期限、蓝牙发送3s超时保持。失焦、切页、最小化、关闭和手动断开仍STOP。

目标deadline扣除10ms时钟量化余量；传输与排队继续缩短期限。完全失联且STOP无法到达时，设备最多保持到最后接受目标的2000ms绝对期限。迟到ACK、遥测恢复、恢复焦点和重新连接均不恢复运动或重发旧命令。

页面区分“连接仍在但延迟”“控制已停止”和“连接已断开”，保留最近主机停止原因。独立事件日志为`data/continuous_events.jsonl`，最多128条，未开启完整录制也保存；包含原因码、序号/请求年龄、两类遥测年龄、积压/队列状态、丢弃增量和MCU stop_reason。STOP先排队，再保存诊断。

## 限幅、记录和事件接口

连续CAPS线速度上限1.18m/s、角速度上限3.75rad/s。默认模式独立限制V/W，原操控按共同倍率等比例限制。本次RAM差速与轮速余量仍约束输出：`min(RAM差速上限, 2×(1.18−|v|))`；页面显示外环/PWM限幅。ARM5有限角速度实验仍独立限制1rad/s。

连续反馈缓存600条，不占有限实验存储。完整录制包含原始字节、`continuous_arm_context`（含input_mode）、`continuous_state`及`continuous_stop`；暂停曲线显示不停止控制与录制。

`ContinuousService.apply_events()`接收`DrivingEvent(source, sequence, generated, command)`列表。同批方向归并，幅值事件逐次计数；来源序号必须单调递增，重复/倒序或生成超过1s的事件丢弃，最多32个来源且满后拒绝新来源。键盘也走此入口，识别器后续应在Qt协调线程接入，健康状态另行定义。
