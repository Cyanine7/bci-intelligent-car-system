# 连续键盘控制

在“连续控制”页使用方向键选择运动方向，Z/X 调整运动快慢。上位机每 **500ms（2Hz）**发送一次当前绝对目标，MCU 以 **100Hz**执行角速度外环和双轮速度内环。

## 使用流程

1. 重启上位机以加载新页面。设备须运行支持连续控制 mode 6 的新固件。
2. 在“角速度环实验”页查询能力，应用并回读所需的内外环 PI 参数。连续控制复用这份 RAM 参数，不自动计算或替换增益。
3. 进入“连续控制”页，点击“查询连续能力”和“读取控制参数”。若从此页开始操作，可先“查询闭环能力”再读取参数；尚未配置的 RAM 需要回角速度页应用参数。
4. 保持静止，点击“采集零偏（2s）”。校准进度沿用角速度服务自动更新；可用“读取IMU状态”再次核对。
5. 未使能时调整基准线速度、角速度，点击“使能连续控制”。键盘焦点自动进入操纵区；等待确认后重新按下方向键。

## 按键

| 按键 | 运动 |
|---|---|
| ↑ / ↓ | 前进 / 后退 |
| ← / → | 原地左转 / 右转 |
| ↑＋← / ↑＋→ | 向左前方 / 右前方行驶 |
| ↓＋← / ↓＋→ | 向左后方 / 右后方倒车；倒车时转向角速度符号随行驶方向反转 |
| Z / X | 倍率乘以1.1 / 0.9；长按每200ms调整一次 |
| 松开方向键 | 对应目标分量立即归零；全部松开后PWM归零，保持本次使能 |
| 空格、页面STOP、顶部STOP | 停车并失能；再次运动须重新使能并重新按键 |

同轴相反方向同时按下时该轴为零，Z/X同时按下时倍率保持。静止时调速只改变倍率。系统键盘自动重复不会生成额外动作。

默认基准为 **0.10m/s、0.30rad/s**，倍率 **100%**，可调范围 **10%～1000%**。Z/X同时调整当前线速度与角速度：例如原地转向0.30rad/s，点按Z变为0.33rad/s，再点按X变为0.297rad/s。无需修改基准角速度。

当前连续控制固件的角速度目标能力上限为 **3.75rad/s**，来自允许的最大轮速差0.6m/s除以轮距0.16m；线速度目标上限为1.18m/s。上位机按实际CAPS限制输入，旧固件若仍报告1rad/s，页面和发送仍按1rad/s限制，须更新BIN才可使用更高目标。原角速度有限实验仍保持其独立1rad/s上限。

按当前运动方向将倍率约束到可执行范围，达到上限后不再暗中累积更大的倍率；按一次X就从实际目标减速。切换到转向时如需限幅，线速度与角速度仍等比例缩小；松开转向键不会自动恢复之前超限的倍率。

实际轮速差还受本次RAM配置和轮速余量限制：`可执行差速上限=min(RAM差速上限, 2×(1.18−|Vx|))`。例如RAM差速上限仍为0.16m/s，其几何折合角速度约1rad/s；提高目标不会扩大这一参数。需要更高实际转速时，先STOP，在角速度页调整所需差速上限、应用并回读，再回连续页使能。界面显示实际CAPS、RAM差速上限及“外环差速已限幅”“轮速PWM已限幅”，用来判断目标是否受限。参数不自动改写。

## 目标与停车

MCU每10ms将执行目标向请求目标推进，线速度变化率0.5m/s²、角速度变化率2rad/s²。非零更新不重建PI或前置滤波状态。换向经过零点；释放的分量直接归零，整体零目标清除控制器并令PWM为零。

松键归零和STOP立即发送，不等待500ms周期或普通目标ACK。窗口失焦、操纵区失焦、切页、最小化和关闭都会清空按键并STOP；返回窗口不会恢复运动。

每个目标携带设备绝对截止时间，有效期上限1000ms；发送端扣除一个10ms控制周期作为时钟量化余量，链路和排队耗时继续缩短有效期。ARM后尚未收到目标也在1000ms后失能。目标ACK超过200ms未确认、STATE过期、连续遥测过期、通信积压/设备丢失或本地禁止时停止；陀螺数据超过60ms由MCU停止。停止后不重发旧目标、不自动使能或重连。

## 参数、显示与记录

使能时冻结当前角速度配置revision、外环PI、左右轮PI、PWM/差速上限和已校准零偏。连续控制与有限实验互斥；参数仍只存RAM。

页面显示请求目标、经过小步过渡的执行目标、反馈线速度/角速度、双轮PWM、倍率和停止原因。连续遥测为20Hz，独立缓存600条，不占用有限实验记录。点击顶部“开始录制”后，原始通信、命令以及`continuous_arm_context`、`continuous_state`进入现有会话记录；暂停曲线显示不停止控制或录制。

## 软件验证

Qt测试使用`PROJECT_V1_FAKE`，覆盖按键、长按、相反方向、优先归零、失焦/切页、超过一分钟的2Hz运行及故障不恢复。实际Host/C字节桥使用生产控制源码，核对100Hz PI/前置滤波递推、非零更新、平滑换向、截止时间、丢ACK、陀螺过期、本地禁止及STOP。

这些是软件验证；本轮未连接、烧录或运动实车。
